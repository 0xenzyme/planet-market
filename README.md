# Planet Market

Factorio 2.1 mod. Spawns a coin market near each planet spawn so you can buy armor, equipment, and modules with coins.

[Mod portal](https://mods.factorio.com/mod/planet-market) · Factorio 2.1 / Space Age

每个星球出生点附近生成金币市场，用金币购买装甲、模块和装备。

## Features

- Auto-spawn an indestructible market on Nauvis and Space Age planets
- 1 coin per minute for connected players (configurable)
- Coin map marker
- Admin commands: `/spawn-market`, `/give-market`

## Settings

- Auto-spawn markets
- Coins paid each minute (`0` disables payout)
- Optional tech disables (off by default)
- Optional speed / crafting bonuses (off by default)

## Install from source

Copy this folder into `%APPDATA%\Factorio\mods` as `planet-market`, or zip it as `planet-market_<version>.zip` and drop the zip into the mods folder.
